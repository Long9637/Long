Xin chào anh em, mình là một Builder thích thực chiến! 🚀

Mình là sinh viên năm 3 ngành Công nghệ Thông tin. Thay vì chạy theo các thuật ngữ hào nhoáng hay các framework phức tạp khi chưa cần thiết, mình tập trung vào việc hiểu sâu bản chất: cách mạng máy tính truyền gói tin, cách trình duyệt render DOM, và cách biến một ý tưởng thành một công cụ chạy ổn định.

Trạng thái hiện tại: Đang tìm kiếm cơ hội thực tập, vừa học vừa build các CLI tool nhỏ phục vụ công việc hàng ngày.

Về bản thân & Triết lý lập trình

Hành trình của mình bắt đầu từ sự tò mò muốn biết cái gì thực sự xảy ra sau khi mình nhấn nút Enter trên trình duyệt. Mình từng thử cài Linux, vô tình làm hỏng bootloader vài lần, tự sửa router ở phòng trọ và viết script tự động tải bài giảng. Những lần "nghịch dại" đó dạy mình nhiều hơn bất kỳ slide lý thuyết suông nào.

Phong cách làm việc của mình:

  • Thực tế là ưu tiên số một: Không overengineering. Giải pháp đơn giản, dễ đọc, dễ debug luôn tốt hơn cấu trúc phức tạp nhưng khó bảo trì.
  • Học bằng cách bắt tay làm (Learn by building): Đọc tài liệu, viết thử nghiệm nhỏ, làm vỡ nó ra xem lỗi ở đâu rồi tối ưu lại.
  • Yêu thích Terminal & Công cụ tối giản: Thích làm việc với dòng lệnh, hiểu cấu trúc file, git workflow và tự viết script tự động hóa những việc lặp đi lặp lại.

Công nghệ & Hộp đồ nghề kỹ thuật

Những công nghệ mình dùng thường xuyên để thí nghiệm và làm dự án:

1. Nền tảng cốt lõi

  • HTML5 Semantic (Viết code đúng chuẩn ngữ nghĩa, tối ưu khả năng truy cập và SEO).
  • CSS3 (Nắm vững Box Model, Flexbox, Responsive Web Design cơ bản).
  • JavaScript (ES6+, DOM API thuần, Async/Await, xử lý bất đồng bộ).

2. Ngôn ngữ & Backend thực chiến

  • Python (Viết script tự động hóa, xử lý dữ liệu và web scraping).
  • Node.js / Express (Xây dựng RESTful API đơn giản, nhẹ nhàng).
  • Golang (Đang học và ứng dụng để viết các công cụ dòng lệnh tốc độ cao).
  • SQL & SQLite / PostgreSQL (Thiết kế bảng, quan hệ dữ liệu và viết truy vấn tối ưu).

3. Môi trường & Công cụ hàng ngày

  • Hệ điều hành: Linux (Ubuntu / Arch), Windows Terminal (PowerShell / WSL2).
  • Quản lý phiên bản: Git, GitHub (Commit atomic, phân nhánh rõ ràng).
  • Docker cơ bản (Đóng gói ứng dụng để chạy nhất quán mọi nơi).

Dự án cá nhân đã hoàn thiện

Dưới đây là một số món đồ chơi công nghệ và công cụ thực tế mình tự thiết kế và xây dựng:

HUD cảnh báo tốc độ Waze

Vấn đề: Khi lái xe trên đường, việc liên tục phải cúi xuống nhìn màn hình điện thoại để canh camera phạt nguội và biển giới hạn tốc độ từ Waze rất dễ làm phân tâm, nguy hiểm và chói mắt dưới trời nắng.

Giải pháp: Chế tạo thiết bị hiển thị kính lái HUD (Head-Up Display) viết bằng C++. Thiết bị kết nối và đồng bộ dữ liệu tốc độ thời gian thực, vị trí camera giám sát từ Waze để phản chiếu trực tiếp lên kính lái, đồng thời kích hoạt buzzer phát tín hiệu cảnh báo tức thì khi chạy quá tốc độ quy định.

Công nghệ sử dụng: C++, Embedded Systems, Bluetooth BLE, Waze Integration.
